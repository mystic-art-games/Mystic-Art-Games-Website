# Website collaboration instructions

The user prefers fast implementation and tests changes personally. Do not run automated tests, manual smoke tests, browser checks, or other post-change verification unless the user explicitly requests it. Report what changed without claiming it was tested.

Create local Git commits for completed changes. Do not push to a remote repository.
# Task completion replies

When the task is complete, the final reply must contain only `Done.`.
When the task is incomplete, the final reply must contain only `Not fully done.`.
Do not report file counts, lines added or removed, or other change statistics in user-facing updates.
